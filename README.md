# GOC · DJI 参考风格产品单页

**从产品资料出发，先做飞书原型，再做大画面、黑白灰的硬件产品页。**

这套技能来自 PixelMob 项目的实际制作，适合沿用这类 DJI 参考风格的产品介绍页。

你负责给资料、定方向、看结果；AI 负责整理文案、画原型、写前端。

[看成果案例：PixelMob 审核页](https://pixelmob-review.vercel.app) · 维护：**GOC** · 版本：**2026.09.23**

## 第一次：让 Codex 安装

准备能正常使用的 Codex 桌面版，在 Chrome 登录飞书。电脑上建一个项目文件夹，用 Codex 打开它，新建任务。

复制这段话给 Codex：

```text
请从 https://github.com/xiaoshikai-git/goc-dji-style-onepage 安装两个技能：
- skills/feishu-website-wireframes
- skills/dji-product-page

先阅读仓库说明，完整安装技能文件夹及关联文件，不要只复制 SKILL.md。
请安装为当前用户可用的技能，并检查浏览器操作工具能否连接我登录的 Chrome。
缺什么请一步步带我配置。已安装时先检查版本，不直接覆盖本地修改。
完成后告诉我两个技能是否可用、浏览器是否连接成功。
```

**看到“两个技能可用、浏览器已连接”，再往下做。** 新装技能未出现时，新开一个任务或重启 Codex。

## 然后：照着做 3 步

### 1. 给资料

把产品资料、图片、视频、Logo 放进项目文件夹。原文件就行，不用先写文案或剪视频。

[需求单：点开后用右上角的下载按钮保存](templates/project-brief.txt)。填好后放进项目文件夹；不会填，就让 AI 逐项问你。

```text
读取我的项目资料，并从技能仓库复制 templates/project-brief.txt 到当前项目，作为需求单。
先从资料里填入已有答案，再问我缺什么。不要覆盖我已填写的需求单。
用几句话说清：做什么产品、给谁看、用户最后要点去哪里。
没确认的产品事实标“待核实”，不要编参数。
```

**你确认它理解对了，就进入下一步。**

### 2. 做原型

在飞书新建文档，正文输入 /，选择“画板”。复制文档链接，把下面的【链接】替换掉：

```text
使用 $feishu-website-wireframes。
按刚确认的需求，在飞书画板【链接】制作可编辑的黑白原型，写好实际文案，
标清图片位置、按钮去向和切换状态。先检查编辑权限；关键素材缺失时标出来。
```

你检查：**卖点是否真实、阅读顺序是否顺畅、按钮去向是否正确。**

确认后告诉 AI：“原型确认，按这个版本做网页。”

### 3. 做网页

继续在同一个 Codex 任务里发送：

```text
使用 $dji-product-page。
按刚确认的原型、文案和项目素材，做成 DJI 参考风格的产品页，适配电脑和手机。
检查图片、视频、按钮和切换功能，启动本地预览，给我可点击的地址。
实现中如需调整原型，说明原因，并同步回原型。
```

打开预览，发“截图 + 位置 + 修改要求”让 AI 改。例如：“第二屏第三张卡，正文缩成两行，保留核心卖点。”

要发给别人审核，再告诉 AI：

```text
页面已确认。请帮我发布一个临时审核版，给我别人也能打开的链接，并确认可用。
需要我登录或补信息时告诉我。
```

本地预览通常只在你的电脑能用。正式上线、域名和 Shopify 接入另行处理。

## 以后怎么用、怎么更新

**安装一次，日常直接使用技能。换电脑需要重新安装。**

仓库更新不会自动同步到你的电脑。需要更新时，把这段话发给 Codex：

```text
请检查 https://github.com/xiaoshikai-git/goc-dji-style-onepage 的最新提交，
更新 feishu-website-wireframes 和 dji-product-page 两个技能。
先核对本地差异并备份；有我改过的内容就保留，遇到冲突再问我，不要直接覆盖。
完成后告诉我安装的版本和提交号。不要修改我的网页项目或已填写的需求单。
```

## 包里有什么

| 技能 | 负责什么 |
| --- | --- |
| [feishu-website-wireframes](skills/feishu-website-wireframes/SKILL.md) | 飞书可编辑黑白原型、实际文案、素材与交接说明 |
| [dji-product-page](skills/dji-product-page/SKILL.md) | 从确认原型实现大画面、黑白灰、胶囊 Tab、克制动效的产品页 |

每个技能都是完整文件夹，`SKILL.md` 是入口，关联文件也要保留。AI 安装时可使用 Codex 的 `skill-installer`，仓库为 `xiaoshikai-git/goc-dji-style-onepage`，安装路径就是上表对应的两个 `skills/…` 目录。安装器遇到已有目录时会停止；更新需另外核对差异、备份和替换。

画原型需要可操作已登录浏览器的工具与目标画板编辑权限。可选绘图脚本需要 Python 3.10+ 和 Pillow，AI 按需检查；安装技能本身不会自动获得浏览器权限。DJI 是风格参考，本包不含其品牌素材，也不是 DJI 官方规范。
