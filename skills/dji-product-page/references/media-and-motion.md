# 素材、动效与实际运行

## 素材选择

优先选择最能证明本段内容的客户真实图片、界面或产品视频。它们之间按清晰度、匹配度与裁切效果选择，不机械规定“视频一定优先”。没有合适素材再考虑新制图；使用 imagegen 时遵循当前可用技能/工具，保留真实产品外形与接口，不能生成伪证据或伪 UI。

为每个关键素材记下文件/来源、功能、时间码（如有）、主体位置、桌面/手机裁切和替代封面。需要从 TVC 获取素材时先看镜头与清晰帧，不把转场、运动模糊或字幕遮挡的帧当主视觉。

判断匹配度：

| 表达内容 | 应看得见的证据 |
| --- | --- |
| 备份 | 插卡、传输进度或完成状态 |
| 数据保护 | 文件校验/备份报告等真实反馈 |
| Review | 照片细节、拍摄参数或回看操作 |
| Cull | 多图选择、分组、标记等真实动作 |
| Create | 编辑界面或效果改变 |
| 连接/交接 | 接口、线材与实际工作站关系 |
| 场景适用 | 人、设备和拍摄环境的关系 |
| 团队/成熟度 | 归属明确的过往产品与真实样机 |

素材无法证明某能力时，换素材或改文案，不能用“看起来科技”补足证据。复杂图需看清关键区域时用上图下文；叠字只放在确实有空间的构图。

## 何时用视频

操作动作比静图增加理解时使用短循环，如选片、调色、接口接续；容量、屏幕规格、硬件结构通常可用静图。不要九张卡全部自动播放。

- Hero：轻量封面先可见，视频真正播放后再淡入；muted、playsinline、loop 与可用暂停按钮。
- 短循环：按镜头自然长度裁切，常见约 3–8 秒；进入附近才缓冲，进视口播放、离屏和后台暂停。
- 完整演示：点击后加载/播放，保留播放器控制和失败反馈。
- Tab：只让活动面板媒体工作；切换暂停上一个，尊重用户手动暂停与 reduced-motion。
- 自动播放失败时保持有效图片兜底，不让播放 promise 报错造成页面异常。

本项目曾使用短视频提前约 600px 缓冲、图片提前约 1600px 预热，这只是该页面的参数。新页面根据媒体体积、网络与滚动实测调整；不要因此预载全页所有视频。

## 统一动效

| 行为 | 本次最终基线 |
| --- | --- |
| 整块入场（含 KV 文字） | opacity 0→1、上移 24px，700ms |
| 位移缓动 | cubic-bezier(.2,.7,.2,1) |
| opacity 缓动 | ease |
| 重播 | 初次进入一次，回滚不重复 |
| Tab 内容切换 | 400ms，约 6px 上移、轻微淡入 |
| 关键数字 | 本次 800 两处为 2300ms；其他数字按价值选用 |
| 控件状态反馈 | 常用 200ms 左右 |

最终认可的是整块节奏；中途的 450–550ms 卡片错峰、逐词入场和 KV 背景缩放没有保留。不要读到历史方案就恢复它。

静态内容默认可见，JS 成功初始化后再增强动画；reduced-motion 直接显示终态，数字显示最终值，非必要视频不自动播。聚焦控件立即可见。不要将整页 opacity:0 后等待所有视频加载，慢网会导致不可读。

数字动画预留最终宽度，数字与单位不跳动，辅助技术读取稳定最终值。保留“Up to”、型号、媒体/配置条件，不能动画时省略。

## 资源与代码

在不破坏清晰度、主体和界面可读性的前提下用响应式 WebP/AVIF、WOFF2、合理视频转码与 MP4 fast-start；保留原文件和用途映射。尺寸属性/aspect-ratio 预留布局，避免加载跳动。

大图 sharp 不等于所有设备都下载 4K。选择尺寸、编码与 preload 时根据真实视口和首屏任务判断；不能把文件总量下降写成首屏提速百分比。

行为用语义化 HTML、局部作用域与可复用组件实现。状态与动画分开，避免隐藏面板仍播放媒体或动画控制 Tab 是否可用。

最终运行本地预览，并检查真正播放、所有 Tab、FAQ、导航、链接及手机裁切。构建通过不能代替浏览器检查；一张静态截图也不能证明播放器正常。
