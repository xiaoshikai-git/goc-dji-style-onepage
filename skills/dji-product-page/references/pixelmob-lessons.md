# PixelMob 复盘与适用边界

依据日期：2026-09-22。依据为项目“制作 PixelMob 首页原型”“制作 Pixelmob Bridge 页面”的用户反馈、最终 `site/` 源码、项目记录与实际页面。

历史明确参考：[DJI SDR Transmission 2](https://www.dji.com/ca/sdr-transmission-2)。参考关系由项目任务记录确认；此技能的尺寸和动效取自 PixelMob 最终实现，不声称它们是 DJI 官网当前参数。新项目不用重新打开客户页面即可使用这些原则。

| 实际反馈/变化 | 可复用判断 |
| --- | --- |
| 原型加入九项亮点，并要求控制文案数量、格式与卡片排版 | 原型阶段按真实尺度测容量 |
| B 版参考 DJI 提议六张视觉卡，最终 HTML 保留九项 | 中途建议不是最终标准；数量依项目 |
| 7-layer 卡片过高，后来降到一行，RAW 卡横向展开 | 卡片跨度跟随画面与信息，不靠加高填版 |
| 多次删掉眉题、章节序号与重复口号 | 信息本身强时让素材与短标题说话 |
| 工作流先独立成段，又要求补回“流”的对比 | 简洁同时保留路径和交接关系 |
| 两套 Tab 统一为有容器的 DJI 参考样式 | 同类交互共用外观与行为 |
| 标题、Tab 和 media 要求版心一致，部分标题改左对齐 | 章节结构有连续基线；Hero 仍可居中 |
| 信任改成团队履历与工作中样机两组证据 | 用可核实内容消除疑虑，不写抽象品牌介绍 |
| Review/Cull/Create 素材分别修正，分享与交接改上图下文 | 图文匹配和主体可见比固定版式重要 |
| 先试快错峰，后回到整块 0.7 秒；800 改为 2.3 秒 | 以用户最终认可节奏为准 |
| 模糊 TVC 截帧换成清晰星空摄影图 | 真实清晰度和构图比素材来源类型更重要 |
| 未确认的尺寸/重量/芯片等参数暂不展示 | 不能为了填表编造数字 |

## 固定在本技能的风格

专业硬件语气、大媒体、Inter、统一版心、黑白灰章节、少量有意义的彩色、胶囊 Tab、整块克制动效。

## 不迁移成其他客户的事实

PixelMob 品牌及文案、800MB/s/24TB、具体型号/奖励链接、UT2 金额和人数、NAB 年份、工程样机状态、客户素材及联系方式，都需要新项目独立提供和核实。九卡、完整页面顺序、是否使用 KS 绿由内容/业务决定。

原始 brief 中“AI 不应是第一卖点”等策略，与最终 Hero 含 AI 的品类名称可以并存；不要机械按老 brief 覆盖最新已认可标题。冲突应根据最新明确决定和事实边界处理。

这次提炼没有改写飞书或当前网站。不能据此宣称原型、上线站点或 Shopify 已同步完成。
